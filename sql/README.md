
# HR Analytics SQL Analysis

## Objective

Analyze employee attrition patterns using SQL and SQLite.

## Database

- Database: SQLite
- Table: employees
- Source: cleaned IBM HR Analytics employee dataset

## Queries Implemented

1. Overall employee attrition
2. Attrition by department
3. Attrition by job role
4. Attrition by overtime
5. Attrition by tenure group
6. Duplicate employee-number validation
7. Attrition category validation
8. Invalid age, income, and tenure checks
9. Tenure-based attrition analysis

## Key Findings

- Overall attrition rate: 16.12%
- Sales department attrition rate: 20.63%
- Sales Representative attrition rate: 39.76%
- Overtime group attrition rate: 30.53%
- Non-overtime group attrition rate: 10.44%

## Tools

- SQL
- SQLite
- Python
- Pandas
- VS Code

## Limitations

These are descriptive findings from sample data.
Observed relationships do not prove causation.
